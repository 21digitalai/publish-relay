# Publish Relay Style Guide

## Design brief pending Designer approval

- Product feel: modern, precise, calm, premium, and fast.
- Authenticated operator workflows are first-class product surfaces.
- Scheduling density must remain legible across account, list, calendar, day, and hour views.
- Motion should communicate navigation, state changes, queue movement, loading, success, and failure; avoid decorative animation that slows work.
- Native/raw controls are unacceptable where domain-aware account selectors, date/time pickers, calendars, status controls, or recovery flows materially improve usability.

Designer must inspect the available design-reference markdown files and produce the concrete palette, typography, spacing, components, motion tokens, responsive behavior, and accessibility rules before UI implementation.
